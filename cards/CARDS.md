# Learning Cards

Four layers per card: **L0** a twelve-year-old can follow → **L1** the mechanism → **L2** how to use it → **limit** when it fails. Gap evidence follows each cluster.

## c27 确定性分工（3 件）— 证据：HN（State of Context Engineering 讨论）：每步都该问"这该进代码还是该给模型"

- **L97 可确定化检测**：L0 有些活 agent 干了一百遍、每次都一样、从不出错——这种活就不该再麻烦模型了，写成死代码又快又稳。L1 统计步骤的历史执行（输入模式固定+输出恒定+零失败），连续 N 次满足 → 建议**确定化**。L2 断言=①100 次恒定建议固化、②输出有变化不建议。
- **L98 分工账本**：L0 家里记账要分"谁花的"：这里记每一步是代码干的还是模型干的、花了多少，月底一看就知道钱去哪了。L1 按步骤记录执行者类型（code/model）+成本，聚合输出分工成本比与趋势。L2 断言=①账本能按类型汇总、②缺类型标记的步骤被列出。
- **L99 确定性复验**：L0 号称"每次都一样"的代码，连跑两次必须一字不差；差一个字，就别叫确定。L1 对标记为确定性的步骤连跑 2 次，输出逐字节比对，不一致 → 撤销确定性标记。L2 断言=①两次不一致摘标记、②一致保留。
